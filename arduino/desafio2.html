Desafio 2

Estacionamento Inteligente

Neste desafio, o objetivo foi desenvolver um sistema de estacionamento utilizando um Arduino, um sensor ultrassônico, um potenciômetro e um LED.

O sistema utiliza a distância de um objeto para determinar o comportamento do LED, criando um alerta visual para indicar a aproximação de um veículo.

Proposta do Desafio

O circuito deveria utilizar um sensor ultrassônico para medir a distância de um objeto. O potenciômetro deveria permitir que o usuário definisse a distância limite de segurança.

A partir dessa configuração, o LED deveria indicar visualmente a proximidade do objeto.

Componentes

  • Arduino
  • Sensor Ultrassônico
  • LED
  • Potenciômetro

Como o sistema funciona

O comportamento do LED muda conforme a distância medida pelo sensor e o limite configurado no potenciômetro.

Desafio adicional

Além do funcionamento básico, foi proposto modificar o programa para que o LED piscasse cada vez mais rapidamente conforme o objeto se aproximasse.

Dessa forma, quanto menor fosse a distância, mais rápido seria o alerta visual, simulando um sistema de assistência para estacionamento.

Código

O código é responsável por realizar a leitura da distância, interpretar o valor configurado pelo potenciômetro e controlar o LED de acordo com a proximidade do objeto. 


const int trig = 9;
const int echo = 10;
const int led = 13;

void setup(){
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
  pinMode(led, OUTPUT);
}

void loop(){
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  long duracao = pulseIn(echo, HIGH);
  int distancia = duracao * 0.034 / 2;

  if(distancia < 10){
    digitalWrite(led, HIGH);
  } else if(distancia < 20){
    digitalWrite(led, HIGH);
    delay(300);
    digitalWrite(led, LOW);
  } else {
    digitalWrite(led, LOW);
  }
}
