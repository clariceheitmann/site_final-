Arduino + Tinkercad

Desafios de Automação

Projetos desenvolvidos utilizando Arduino no Tinkercad, simulando situações reais da Indústria 4.0 com sensores e automação.

Sobre os projetos

Os desafios foram desenvolvidos com o objetivo de aplicar conceitos de automação utilizando Arduino, sensores e lógica de programação. Cada projeto simula uma situação real, envolvendo tomada de decisão baseada em dados do ambiente.

Desafio 1 - Iluminação Inteligente

Sistema automático que controla um LED com base na presença de pessoas e na luminosidade do ambiente.

Ver projeto

Desafio 2 - Estacionamento Inteligente

Sistema que utiliza sensor ultrassônico para medir distância e indicar a proximidade de veículos com sinais visuais.

Ver projeto

Desafio 3 - Ambiente Inteligente

Sistema automatizado que monitora temperatura e umidade, indicando condições ideais ou críticas do ambiente.
