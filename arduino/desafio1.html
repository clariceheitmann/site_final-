Desafio 1

Iluminação Inteligente

Neste desafio, o objetivo foi desenvolver um sistema de iluminação automática utilizando um Arduino, um LED, um sensor de presença/movimento e um sensor de luminosidade.

Proposta do desafio

O circuito deveria controlar automaticamente um LED de acordo com a presença de uma pessoa e com a quantidade de luz existente no ambiente.

Dessa forma, o sistema simula uma iluminação inteligente, capaz de evitar que a luz permaneça ligada quando não existe necessidade.

Componentes utilizados

  • Arduino Uno
  • LED
  • Sensor de presença (PIR)
  • Sensor de luminosidade (LDR)

Como o sistema funciona

O LED acende apenas quando duas condições são atendidas: presença detectada e ambiente escuro. Caso haja luz ou ausência de movimento, o LED permanece desligado.

Código do Arduino

O código abaixo é responsável por receber as informações dos sensores e controlar o estado do LED de acordo com a lógica proposta no desafio. 


const int led = 13;
const int pir = 2;
const int ldr = A0;

void setup() {
  pinMode(led, OUTPUT);
  pinMode(pir, INPUT);
  Serial.begin(9600);
}

void loop() {
  int movimento = digitalRead(pir);
  int luz = analogRead(ldr);

  if (movimento == HIGH && luz < 500) {
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }
}
