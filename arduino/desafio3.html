Desafio 3

Ambiente Inteligente

Sistema automatizado que reage às condições do ambiente utilizando sensores.

01

Proposta do desafio

O sistema deveria realizar a leitura da temperatura e da umidade da estufa e comparar os valores obtidos com referências estabelecidas na programação.

A partir dessas informações, os LEDs deveriam indicar visualmente se as condições do ambiente estavam adequadas ou se algum dos parâmetros estava fora do limite definido.

02

Componentes utilizados

  • Arduino
  • LED verde
  • LED vermelho
  • LED amarelo
  • Sensor de temperatura
  • Sensor de umidade
03

Como o sistema funciona

O sistema lê os valores de temperatura e umidade através de sensores analógicos. A partir dessas leituras, ele determina se o ambiente está em condições ideais. Caso a temperatura esteja fora do intervalo aceitável ou a umidade esteja baixa, LEDs indicam o estado do ambiente em tempo real.

06

Código Arduino 

const int tempPin = A0;
const int umidadePin = A1;

const int verde = 8;
const int amarelo = 10;
const int vermelho = 12;

void setup() {

  Serial.begin(9600);

  pinMode(verde, OUTPUT);
  pinMode(amarelo, OUTPUT);
  pinMode(vermelho, OUTPUT);

}

void loop() {

  int leituraTemp = analogRead(tempPin);

  float tensao = leituraTemp * (5.0 / 1023.0);

  float temperatura = (tensao - 0.5) * 100;

  int umidade = analogRead(umidadePin);

  Serial.print("Temperatura: ");
  Serial.print(temperatura);

  Serial.print(" C   Umidade: ");
  Serial.println(umidade);

  digitalWrite(verde, LOW);
  digitalWrite(amarelo, LOW);
  digitalWrite(vermelho, LOW);

  bool temperaturaRuim = temperatura > 30 || temperatura < -10;
  bool umidadeBaixa = umidade < 50;

  if (temperaturaRuim) {
    digitalWrite(vermelho, HIGH);
  }

  if (umidadeBaixa) {
    digitalWrite(amarelo, HIGH);
  }

  if (!temperaturaRuim && !umidadeBaixa) {
    digitalWrite(verde, HIGH);
  }

  delay(500);

}
